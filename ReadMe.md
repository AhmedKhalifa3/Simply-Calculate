## Simply Calculate
The program offers the following key functionalities:

*   **Simple Calculator** [1]
    *   Addition [1]
    *   Subtraction [1]
    *   Multiplication [1]
    *   Division [1]
    *   Modulus [1]
*   **Scientific Calculator** [1, 2]
    *   Get the square root of a real number [1].
    *   Get the cubic root of a real number [1].
    *   Get the absolute value of a number [1].
    *   e to the power of a number x [1].
    *   Prime factorization of a real integer [1].
    *   Factorial of a real integer [1].
    *   Log of a real number [1].
    *   Natural log of a real number [1].
    *   Get the result of a real number raised to a real number [2].
    *   Sin of a real angle [2].
    *   Cos of a real angle [2].
    *   Tan of a real angle [2].
    *   Shift sin, cos, tan (Inverse trigonometric functions) [2].
    *   Solve first-degree equation of the form y = ax + c [2].
    *   Solve second-degree equations of the form: y = ax^2 + bx + c [2].
    *   Summation of many numbers [2].
    *   Multiplication of many numbers [2].
*   **Encoding and Decoding** of a given word [2].
*   **Display the data stored in the file** (history) [2].
*   **Clear the data from the file** [2].
